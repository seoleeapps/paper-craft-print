# Paper Craft Print 개인정보처리방침 원고

상태: 공개 전 검토 원고. 시행일은 공개 페이지를 게시할 때 확정한다. 공개 페이지 예정 주소는 `https://www.seorilabs.com/apps/paper-craft-print/privacy/`이며 게시와 응답은 확인하지 않았다.

## 앱과 문의

Paper Craft Print는 Seolee Apps에서 배포하는 성인 취미 사용자를 위한 Android 종이 도안 편집 앱입니다. 개인정보 관련 문의는 `cs@seorilabs.com`으로 보내 주세요.

## 기기에 보관하는 정보

앱은 초안, 문구, 크기와 패턴 설정, 선택한 사진 사본, 생성한 PDF, 언어 설정, 광고로 연 패턴의 사용 권한을 기기에 보관합니다. 로그인, 앱 서버, 클라우드 동기화, Firebase, 별도 이용 분석 또는 결제 기능은 사용하지 않습니다. 선택한 사진과 초안을 앱 운영자의 서버에 업로드하지 않습니다.

사진은 사용자가 시스템 사진 선택기에서 고릅니다. 앱은 사진 전체 목록, 카메라와 마이크 접근 권한을 요청하지 않습니다. 사용자가 선택한 사진은 도안 편집과 PDF 생성에 사용합니다.

## 파일 저장, 공유와 인쇄

사용자가 선택하면 PDF를 시스템 폴더 선택기로 고른 위치에 저장하거나 시스템 공유와 인쇄 기능에 전달합니다. 전달 후 파일을 처리하는 앱, 서비스, 프린터에는 해당 제공자의 정책이 적용됩니다. 외부에 저장하거나 전달한 파일은 이 앱에서 삭제되지 않습니다.

## 광고와 개인정보 선택

홈과 내 작업에는 Google AdMob 배너 광고가 표시될 수 있습니다. 일부 추가 패턴은 사용자가 선택한 보상형 광고를 완료하면 해당 초안에 열립니다. 동의 확인 뒤 광고 요청이 허용된 상태에서 Google Mobile Ads SDK를 초기화합니다. 광고가 허용되지 않거나 제공되지 않아도 무료 도안과 기본 패턴으로 제작하고 PDF를 만들 수 있습니다.

Google Mobile Ads와 User Messaging Platform은 광고 제공, 측정, 오류 진단과 부정 이용 방지를 위해 IP 주소, 광고 상호작용, 진단 정보와 기기 식별자 등의 정보를 처리할 수 있습니다. IP 주소는 대략적인 위치를 추정하는 데 사용될 수 있습니다. 광고 SDK가 수집하는 사용자 데이터는 전송 중 암호화됩니다. 광고 식별자는 Android 설정에서 재설정하거나 삭제할 수 있습니다. 지역과 동의 상태에 따라 처리 범위가 다를 수 있습니다.

설정의 광고 개인정보 선택에서 이용 가능한 동의 선택을 확인하고 변경할 수 있습니다. Google의 데이터 처리와 관리 방법은 [Google 개인정보처리방침](https://policies.google.com/privacy)과 [광고 기술 안내](https://policies.google.com/technologies/ads)를 참고하세요. 광고 제공자의 보관 기간과 삭제 절차는 해당 정책을 따릅니다.

## 보관과 삭제

초안은 사용자가 삭제하거나 앱 데이터를 지울 때까지 기기에 남습니다. 삭제한 초안에서만 사용하던 사진 사본은 더 이상 다른 초안에서 참조하지 않으면 정리합니다. 앱 내부에 생성한 PDF는 초안 삭제만으로 지워지지 않습니다. 앱 데이터 삭제 또는 앱 삭제 시 앱 내부 데이터가 지워집니다. 외부 폴더나 다른 서비스에 저장한 파일은 해당 위치에서 직접 삭제해야 합니다. Android 자동 백업은 비활성화되어 있습니다.

## 대상과 변경 안내

앱은 성인 취미 사용자를 대상으로 하며 아동을 대상으로 설계하지 않았습니다. 기능이나 데이터 처리 방식이 바뀌면 이 방침을 수정하고 공개 페이지의 시행일을 갱신합니다.
