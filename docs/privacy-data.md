# 데이터·SDK 목록 — 제출 전 검토 자료

앱은 초안과 설정을 SQLite, 선택한 사진 사본과 PDF를 앱의 지속 저장 폴더에 보관한다. 서버 업로드·로그인·이용 분석·Firebase·결제는 없다. 사용자가 선택한 시스템 폴더에 PDF를 저장하고 시스템 공유·인쇄 창에 파일을 전달할 수 있다. 초안 삭제 시 다른 초안이 참조하지 않는 사진을 정리한다. 앱 삭제 시 내부 데이터는 삭제되며 외부에 저장·공유한 파일은 남는다. Android 자동 백업은 비활성화했다.

Google Mobile Ads / UMP는 선택적 보상형 광고와 지역에 따른 동의를 처리한다. 앱 시작 시 광고 자동 측정을 지연하고 동의 상태의 `canRequestAds` 확인 뒤 SDK를 초기화한다. 광고 요청·기기 식별자·네트워크 정보 등의 공급자 데이터 처리가 있으며 스토어 Data safety 작성 시 실제 사용 버전의 Google 공식 공개 목록을 다시 검토해야 한다. 광고 동의 불가·오류·취소 시 무료 패턴으로 제작을 계속할 수 있다. 광고 보상은 서버 검증을 사용하지 않는 로컬 패턴 권한이다.

사진은 Android 시스템 Photo Picker를 이용하며 미디어 전체 접근·카메라·마이크 권한을 요청하지 않는다. 폴더 저장은 Storage Access Framework에서 사용자가 선택한 디렉터리 권한을 이용한다. 광범위 저장 권한은 차단한다.

개인정보처리방침 공개 페이지, Play Data safety·등급·대상 연령·광고 선언은 이번 구축에서 제출하지 않았다. 앱을 스토어에 제출하기 전에 실제 SDK·배포 설정과 맞춰 확정해야 한다.
