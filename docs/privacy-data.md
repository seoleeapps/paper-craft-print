# 데이터와 SDK 목록, Google Play 신고 검토 자료

앱은 초안과 설정을 SQLite, 선택한 사진 사본과 PDF를 앱의 지속 저장 폴더에 보관한다. 서버 업로드·로그인·이용 분석·Firebase·결제는 없다. 사용자가 선택한 시스템 폴더에 PDF를 저장하고 시스템 공유·인쇄 창에 파일을 전달할 수 있다. 초안 삭제 시 다른 초안이 참조하지 않는 사진을 정리한다. 앱 삭제 시 내부 데이터는 삭제되며 외부에 저장·공유한 파일은 남는다. Android 자동 백업은 비활성화했다.

Google Mobile Ads와 UMP는 홈과 내 작업의 배너, 선택적 보상형 광고, 지역에 따른 동의를 처리한다. 앱 시작 시 광고 자동 측정을 지연하고 동의 상태의 `canRequestAds` 확인 뒤 SDK를 초기화한다. 광고 동의 불가, 오류, 취소 시 무료 패턴으로 제작하고 PDF를 만들 수 있다. 광고 보상은 서버 검증을 사용하지 않는 로컬 패턴 권한이다. 편집, 출력 확인과 완료 화면에는 배너를 표시하지 않는다.

사진은 Android 시스템 Photo Picker를 이용하며 미디어 전체 접근·카메라·마이크 권한을 요청하지 않는다. 폴더 저장은 Storage Access Framework에서 사용자가 선택한 디렉터리 권한을 이용한다. 광범위 저장 권한은 차단한다.

2026-10-21 개인정보처리방침의 한국어와 영어 공개 페이지가 HTTP 200과 제품 및 패키지 내용 확인을 통과했다. Play에는 영어 URL을 저장했다. Data safety, IARC, 대상 연령 18세 이상과 광고 선언은 Console에 저장했으며 앱 콘텐츠의 주의 필요 목록이 비어 있음을 읽었다. 같은 후보 1.0.0(1)을 Console 제출1로 심사 제출했으며 검토 중이다. 공개는 아직 진행하지 않았다.

## Data safety 작성 근거

아래는 2026-10-21 소스, 실제 AAB와 Google 공식 자료를 대조해 Console에 저장한 답안의 근거다. 저장된 답안은 [Data safety CSV](../play-store/policy/data-safety.csv)에 있다. 광고 SDK를 포함하므로 앱 전체를 `수집 또는 공유 없음`으로 신고하지 않는다.

| 데이터 | 앱의 처리와 신고 검토 |
| --- | --- |
| 사진, 입력 문구와 초안 | 기기에서 편집하고 PDF를 만든다. 앱 운영자의 서버로 전송하지 않는다. 사용자가 외부 공유한 파일은 수신 앱에서 처리 |
| 언어와 도안 설정, 패턴 권한 | 기기에 보관. 앱 서버와 별도 분석 서비스 전송 없음 |
| 광고 SDK 데이터 | Google 공식 공개 목록의 IP 기반 대략적 위치, 광고 상호작용, 진단 정보, 기기 식별자 범주를 최종 SDK와 대조 |
| 로그인, 결제, 연락처 | 관련 기능 없음. 계정 생성이나 계정 삭제 URL 요구 여부는 현재 Console 질문과 대조 |

Google Mobile Ads 공식 안내는 광고, 분석과 부정 이용 방지 목적의 자동 수집과 공유, TLS 전송을 설명한다. 여기의 분석 목적은 광고 제공자의 처리이며 Firebase나 별도 제품 이용 분석을 추가했다는 뜻이 아니다. 수집의 필수 또는 선택 여부, 일시 처리, 공유 예외, 각 세부 목적과 삭제 답안은 실제 AAB SDK 설정과 현재 Console 정의를 대조해 저장했다. 광고 동의를 받을 수 있다는 사실만으로 모든 수집을 선택 사항으로 표시하지 않는다.

현재 잠금 파일의 React Native 래퍼는 `react-native-google-mobile-ads 17.2.0`이다. 실제 서명 AAB의 dependency graph에서 Google Mobile Ads `25.4.0`, UMP `4.0.0`과 Ads identifier `18.0.0`을 읽었다. Google의 현재 공개 목록은 최신 `25.5.0`을 설명하므로 버전은 구분해 기록했다. 같은 classic SDK의 자동 수집 공개 목록을 근거로 대략적인 위치, 앱 상호작용, 진단과 기기 또는 기타 ID의 수집과 공유를 신고했다. 각 유형은 광고 또는 마케팅, 광고 제공자의 분석과 부정 이용 방지 목적이며 일시 처리로 표시하지 않았다. 모든 사용자에게 수집 중지 선택을 보장하지 않으므로 필수로 표시했다. 별도 제품 이용 분석과 중개 광고 SDK는 추가하지 않았다.

실제 AAB와 APK에서 `allowBackup=false`, 디버그 비활성, 광고 ID와 네트워크 권한, 지연 측정 초기화를 확인했다. 카메라, 마이크와 광범위 사진 및 저장 권한이 없음을 확인했다. 네이티브 Photo Picker, 폴더 저장, 공유와 인쇄 동작은 개발 환경 검수 결과와 별도로 남겨 두고 실제로 실행하지 않은 항목을 통과로 쓰지 않는다.

## 삭제 범위

초안 삭제와 앱 데이터 삭제는 범위가 다르다. 초안 삭제 후 다른 초안에서 사용하지 않는 사진 사본은 정리하지만, 이미 생성한 앱 내부 PDF는 초안 삭제로 지우지 않는다. 앱 삭제 또는 앱 데이터 삭제 시 내부 초안, 사진, 설정, 권한과 PDF가 삭제된다. 사용자가 외부에 저장하거나 공유한 PDF는 그 위치에서 직접 삭제해야 한다. 광고 제공자 데이터의 보관과 삭제는 Google 정책과 제공되는 제어 수단을 따른다.

## 현재 저장 답안과 남은 확인

1. 실제 AAB의 SDK 버전, 광고 ID, 권한과 TLS 공개 자료를 대조했고 Console 답안을 저장했다.
2. 개인정보처리방침의 한국어와 영어 URL, 연락처와 내용을 실제 공개 페이지에서 확인했다.
3. 로그인과 계정 생성은 없으며 외부 계정 로그인도 없다. 광고 제공자 데이터의 삭제 요청을 앱이 직접 이행하지 않으므로 삭제 요청 방법 제공은 아니요로 신고했다. 로컬 초안 및 외부 PDF 삭제와 구분한다.
4. 실제 Android 배너와 UMP, 사진 선택과 OS 파일 전달은 미실행이며 기기 사용 승인 대기다. 개발 환경 대역의 통과와 구분한다.
